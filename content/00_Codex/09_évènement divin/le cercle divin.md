# Le Cercle Divin

---

## Nature du Cercle

Le Cercle Divin n’est pas une guerre.

Ce n’est pas une guerre sainte.

Ce n’est pas un tournoi politique.

C’est un **événement cyclique cosmique**.

Tous les 2000 ans, les douze divinités majeures quittent temporairement l’ordre du monde pour entrer dans une zone hors du temps :

> Le Domaine du Cercle.

Dans cet espace, les dieux ne sont plus des symboles.

Ils redeviennent des individus.

---

## Origine

L’origine du Cercle Divin est inconnue.

Trois théories coexistent parmi les dieux :

### 1 — L’Accord Originel
Les douze dieux auraient créé ensemble le Cercle comme un moyen de mesurer leur évolution.

### 2 — L’Initiative Fragmentée
Chaque dieu aurait contribué sans conscience globale du projet.

Certaines rumeurs impliquent discrètement [[Astringa]] comme influence initiale.

### 3 — Le Mystère du Treizième Écho
Certains textes interdits évoquent une influence indirecte de [[Frihion]].

Mais cette théorie est considérée comme dangereuse et instable.

---

## Création du Domaine

Le Domaine du Cercle est une création conjointe de :

- [[Maylïve]] → stabilisation du temps
- [[Maïlaive]] → isolement hors des cycles de fin

Ensemble, elles créent une zone paradoxale :

> Un espace qui existe sans appartenir au temps.

---

## Nature du Domaine

Dans le Cercle :

- le temps est compressé
- les blessures ne laissent pas de traces permanentes
- la mort n’est pas définitive
- les conséquences existent… mais sont réversibles

Les mortels n’y ont aucun accès.

Aucun événement du Cercle n’influence directement le monde réel.

---

## Objectif réel du Cercle

Officiellement :

> Déterminer la forme actuelle de l’équilibre divin.

Mais en réalité, le Cercle sert à :

- tester les limites des dieux
- relâcher les tensions accumulées
- réactualiser les rapports de force
- réaffirmer les liens entre divinités

C’est à la fois :

- un combat
- une réunion
- une fête
- une mémoire collective

---

## Règles fondamentales

### 1 — Pas de victoire absolue permanente
Aucune mort divine n’est définitive dans le Cercle.

### 2 — Tous les dieux participent
Aucun refus n’est accepté (sauf anomalie cosmique majeure).

### 3 — Pas de destruction du domaine
Les capacités sont naturellement limitées par la structure du Cercle.

### 4 — Le monde extérieur est isolé
Aucune interférence extérieure possible.

---

## Alliances

Les alliances sont autorisées.

Mais elles sont :

- temporaires
- instables
- stratégiques

Une alliance ne garantit jamais la loyauté.

Dans le Cercle :

> Une alliance est une hypothèse, jamais une vérité.

---

## Déroulement du Cercle

### Phase 1 — L’Entrée

Les douze dieux arrivent ensemble dans le Domaine.

Puis entrent un à un dans l’arène principale.

Une lecture cérémonielle est effectuée :

- texte officiel volontairement archaïque
- validé par les douze
- symbolique plus que fonctionnel

---

### Phase 2 — L’Installation

Les dieux explorent le domaine.

Les premières alliances se forment.

Les tensions anciennes réapparaissent.

---

### Phase 3 — Les Combats

Les affrontements commencent.

Ils sont :

- brutaux ([[zentetsu]])
- stratégiques ([[Sÿranaée]])
- chaotiques ([[Frihion]])
- expérimentaux ([[Argarax]])
- instinctifs ([[Syriabéa]])

---

### Phase 4 — Les Banquets

Tous les deux jours :

Pause obligatoire.

Les dieux se retrouvent au centre du Cercle.

Ils mangent, boivent, parlent.

C’est la phase la plus importante du Cercle.

C’est là que les vraies relations se révèlent.

- rivalités anciennes
- amitiés impossibles
- souvenirs partagés
- tensions silencieuses

---

### Phase 5 — La Fin

Le Cercle se termine par :

> L’Explosion du Domaine

La bulle temporelle se désagrège.

Aucun dieu n’en garde de séquelles permanentes.

Ils retournent dans le monde réel.

---

## Le Vainqueur

Il n’existe aucune récompense matérielle.

Le vainqueur reçoit :

- un statut symbolique
- une reconnaissance temporaire
- une perception ajustée des autres dieux

Mais surtout :

> Le droit d’avoir “été le plus proche de l’équilibre actuel”.

---

## Le Vrai Sens du Cercle

Le Cercle n’est pas une compétition.

C’est une **réinitialisation sociale divine**.

Sans lui :

- les conflits s’accumuleraient
- les dieux cesseraient de se comprendre
- les alliances deviendraient permanentes ou toxiques
- le panthéon se rigidifierait

Avec lui :

> Les dieux restent vivants.

---

## Dernière vérité

Ce que les dieux appellent le Cercle Divin…

les mortels ne le verront jamais.

Mais chaque 2000 ans, sans le savoir :

> le monde entier respire au rythme de leurs retrouvailles.

---

## Note finale

Le Cercle n’est pas ce qui oppose les dieux.

C’est ce qui les empêche d’oublier qu’ils ont été, un jour :

> ensemble.
